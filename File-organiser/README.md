# File Organizer
A safe desktop-folder organizer that groups files by extension.

## Features
- Preview changes before moving anything
- Organize into Documents, Images, Videos, Audio, Archives, and Other
- Ignores the script itself
- Handles filename collisions
- Dry-run mode by default

## Run
```bash
python File-organiser.py /path/to/folder
python Files-organiser.py /path/to/folder --apply
```
