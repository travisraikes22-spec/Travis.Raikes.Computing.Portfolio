Projects

Habit Tracker — Python & SQLite

A command-line habit-tracking application using Python and SQLite.

The project demonstrates database design, persistent storage, date-based processing, database relationships, validation, exception handling and streak-calculation logic.

Expense Tracker — Python & SQLite

A persistent expense-management application using Python and SQLite.

The project demonstrates SQL database operations, aggregation, category and date-based summaries, input validation and CSV export.

File Organiser — Python

A command-line automation application that organises files according to their extensions.

The project demonstrates Python file-system programming, pathlib, shutil, argparse, dry-run functionality and filename collision handling.

Quiz Master — Python & JSON

A structured quiz-data project using JSON to store questions, categories, options and answers.

The project demonstrates structured data organisation and Python/JSON project development.
